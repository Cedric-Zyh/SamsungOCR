# 印章检测复用与结果对照

日期：2026-10-24

## 优化范围

印章方向校正、横排共识和局部版式分析会生成内容相同但路径不同的图片。本轮仅在单张回单的一次识别内复用这些重复的文字框检测结果。

复用条件包括完整文件内容的 SHA-256、文件后缀、模型规格、检测与识别模型、推理引擎以及图片尺寸。相同像素但编码不同的文件也分别识别。文件内容和版本在读取前后及推理后均检查，避免临时文件被覆盖时复用错误结果。

权限检查仍先于缓存读取。成功的空结果可以复用；异常和带错误标记的模型响应不能复用。返回值使用深拷贝，任务结束后释放缓存，不与其他回单或下一次重试共享。

角度候选、缩略图和全尺寸的回退规则、源图增强、横排投票、OCR 模型、输入像素、置信度阈值、印章文字比较和最终判定均保留。原来的本地预测串行保护也保留。

结果中的 `processing_timings.text_box_ocr_cache_hits` 记录跳过的重复框检测次数，`paddle_text_box_inference.calls` 仍表示真正调用模型的次数。

## 离线验证方法

工具位于 `tools/analysis/operations/benchmark_seal_reuse.py`。同一进程预热本地模型后，以交替顺序运行禁用复用的基线和启用复用的版本；第一张基线还与预热结果比较，检查自身稳定性。

清瞳使用历史结果中保存的完整响应，保留原识别方案和印章定位。验证进程封禁网络连接，不启动应用或任务工作进程，两个业务数据库均以只读方式打开。标准章数据读取为固定快照；两版使用相同快照执行标准章核验。

对照保留文字、顺序、置信度、坐标、方向、候选关联、判定和证据，仅排除根级耗时字段及临时目录身份；所有生成图片按对应路径比较尺寸、模式和解码后的像素。识别失败、没有实际本地模型调用、网络调用尝试或重放次数异常都不能算作等价通过。

可用以下命令复现；结果和图片写入独立的运行目录，不回写已有识别记录：

```sh
PADDLE_PDX_DISABLE_MODEL_SOURCE_CHECK=True python -m tools.analysis.operations.benchmark_seal_reuse \
  --result-ids 1858 1857 1846 1842 1843 1875 1814 \
  --repeats 1 --output output/ocr-reuse-benchmark
```

以上编号属于当前样单数据库，其他机器需选择其实际存在的结果编号。

验证覆盖真实本地 OCR、历史清瞳定位、标准章核验与生成图片；没有测量真实网络等待，未启用基于历史图片的视觉参考匹配器。这个限制同时适用于基线和复用版本。

## 本机对照结果

7 张样单覆盖方向搜索失败的红圆章、蓝圆章、横排共识成功、矩形章和多印章。前三种各做 3 次配对，其余各做 1 次，共 13 组配对。全部识别结构比较通过，395 对生成图片的尺寸、模式及像素一致；网络请求尝试为 0。

13 组对照的实际框检测调用合计从 342 次降到 251 次，减少 26.6%；实测墙钟时间合计从 152.34 秒降到 134.52 秒，减少 11.7%。单次耗时受本机负载波动影响，表中重复样本使用中位数，不能将这一组数据当作所有样单的稳定提速幅度。矩形章本身几乎没有重复框检测，本轮对其没有预期的明显提速。

完整运行信息保存在：

- `output/ocr-reuse-benchmark/run-20261023-170650-38339000/report.json`：3 张样单的交替重复配对。

## 生效方式

已有服务进程需要重启后加载新代码。应在当前批次完成后重启，避免中断正在识别的任务。历史结果不会自动重写。
