# 结构优化长任务

状态：已完成并验收（2026-11-10）。

目标：收紧职责、依赖、数据交接和状态归属，保持 HTTP 接口、持久化格式、识别规则及人工复核语义兼容。

## 实施阶段

1. 样单分层：独立业务包；显式依赖；列表读模型、队列策略与资源生命周期分离；HTTP 层只做请求响应适配。
2. 持久化：抽出中立的任务状态投影与结果版本计算；建立具有明确语义的写入入口；保持事务内审计、摘要和统计一致。
3. 前端：统一跨页面结果失效通知；样单数据会话独立管理请求合并、版本和刷新节奏；页面负责展示与操作编排。
4. 印章：执行输入任务与展示证据分离；按现有先后次序拆分预处理职责。
5. 流水线：收敛远程来源调度；阶段结果和文档快照使用实际参与运行的交接对象；同步与异步共用结果解释逻辑。
6. 集成验收：补齐依赖边界检查，执行受影响模块和完整前后端回归，记录已验证范围。
