# UI 第二轮优化

本轮围绕工作台状态、长列表操作、图片异常恢复与统计口径改善日常使用。第一轮的筛选范围、连续复核、快捷键和图片缩放继续保留。

## 工作台：从统计数字直接进入需要处理的回单

- 总量、待处理、通过、失败和待复核统计卡可以点击，直接切换下方列表；卡片与状态筛选按钮同步显示选中状态。
- 识别结束后，标题继续提示尚待人工复核和识别失败的数量，方便判断下一步工作。
- 进度说明省略数量为零的处理阶段，减少重复的“0 张”信息。
- 刷新失败时说明当前保留的是上次成功结果；切换日期后加载失败，则隐藏前一个日期的回单，避免把旧日期结果误认为当前结果。
- 空列表说明是所选日期没有回单，还是当前状态筛选没有结果，并提示可采取的下一步操作。

## 回单记录：长表浏览与批量操作更清楚

- 工作台和回单列表在独立区域内滚动，表头保持可见；右侧操作列继续固定，长表与横向浏览时都能找到操作入口。
- 回单记录可选择每页 25、50 或 100 张，并记住当前浏览器的选择。更改每页数量后回到第一页，保留筛选范围。
- 勾选后显示“本页已选”数量，增加“取消选择”。
- 批量确认前，提前提示有多少张仍需逐张确认日期或印章；条件不满足时禁用“批量确认通过”，并保留“复核选中”入口。
- 批量操作期间显示正在处理的状态，限制重复提交。
- 查询无结果时提供“清除附加筛选”；清除时保留导入日期和任务范围。记录加载失败时提供“重新加载”，便于就地恢复。

## 图片查看：区分等待、无图与加载失败

- 图片正在加载、没有可用图片、图片加载失败分别显示明确状态，避免只看到空白预览区。
- 加载失败后可点击“重新加载”；日期或印章区域图片无法打开时，可返回查看整页回单。
- 查看区域的按钮与当前图片保持对应，便于确认正在对照日期、印章还是整页。
- 图片恢复期间保留复核表单及已填写内容。

## 质量统计：让百分比有明确的参评数量

| 指标 | 页面显示的口径 |
| --- | --- |
| 已标注字段准确率 | 正确字段数 / 参评字段数。 |
| 商品单元格准确率 | 正确单元格数 / 参评单元格数。 |
| 日期识别准确率 | 正确日期样本数 / 日期参评样本数；另显示有日期样本中的检出情况。 |
| 印章结论准确率 | 正确印章结论数 / 印章参评样本数。 |
| 待人工复核 | 当前统计范围内待复核回单数，同时说明该范围的总回单数。 |
| 评测真值覆盖 | 真值条目数 / 数据图片数；无图片或数量范围不一致时显示提示。 |

分母为零或缺少有效评测值时显示“—”，有参评样本但全部错误时仍显示真实的 0%。页面同时说明准确率只反映参评样本。

字段与商品明细按照准确率由低到高排列，并附正确数和参评数。各识别方式对比增加独立的字段、商品、日期、印章参评数量，方便理解不同样本范围；旧响应缺少数量时显示“数量未提供”。平均耗时只在存在计时样本时显示，否则提示“暂无耗时数据”。

错误类型按标记次数由多到少显示条形，同一回单可能计入多项。没有错误标记时说明其含义，避免将它直接理解为所有回单已经确认通过。

统计刷新期间保留上次结果并提示正在更新；失败后说明结果尚未更新，支持重新刷新。首次加载失败会替换持续等待的占位内容，显示可重试提示。

## 键盘与窄屏

- 按钮、链接、表单输入和滚动列表具有可见的键盘焦点。
- 长列表区域可通过键盘获得焦点并滚动。
- 窄屏下统计卡、分页操作与选择工具栏自动换行，质量报告明细切换为单列。
- 统计和设置页沿用工作台的导航宽度与标题样式，减少切换页面时的布局变化。复核页通知移至顶部，避免遮挡底部保存与确认按钮。
