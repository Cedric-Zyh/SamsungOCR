# UI 与连续复核优化

本轮围绕查找回单、对照原图和连续复核减少操作，保留原有识别与人工确认规则。

## 已完成的 8 项改进

1. **复核范围明确**：增加“复核当前筛选”“复核选中”“复核当天全部”，复核页持续显示范围；下一张、翻页和刷新沿用进入时的范围。
2. **复核页更紧凑**：压缩问题提示和卡片留白，日期、印章的要求值与识别值并排显示，详细依据可展开查看。
3. **窄屏操作更方便**：固定列表右侧操作列，较窄窗口隐藏处理时间；支持舒适、紧凑显示，并记住当前浏览器的选择。
4. **确认动作更清楚**：用“同一天／修改日期”“印章匹配／不匹配”代替单独符号；底部提示尚未确认或不一致的项目，条件满足后才能确认通过。
5. **突出真正的问题**：总体结论保留主要标记，日期和印章采用较轻的状态提示；日期不一致时突出差异值。
6. **搜索与筛选可见**：常驻搜索框支持查找文件名、订单号或客户；当前筛选显示为可单独移除的标签。
7. **连续复核有进度**：显示本轮已处理、待处理、稍后数量，重复保存同一回单不会重复计数；增加保存、确认和定位快捷键。
8. **图片查看更顺手**：支持拖拽移动、按住 Ctrl／⌘ 滚轮缩放；可调整图片与复核面板宽度，并记住宽度设置。

## 复核范围与稍后处理

| 入口 | 范围 |
| --- | --- |
| 复核当前筛选 | 保留进入时的导入日期、搜索、客户、核验状态等条件，覆盖全部结果页。后续修改列表筛选不会改变已开始的范围。 |
| 复核选中 | 仅处理勾选回单的 ID；空选择不能变成全部回单。 |
| 复核当天全部 | 使用当前选择的日期，忽略客户等列表筛选；当天工作队列中的重试回单也按该日期归入范围。 |

所有连续复核队列均由后端判定哪些回单仍可复核，排除已确认、识别失败和正在处理的回单。多页回单先合并，再筛选和分页。单独打开已确认记录可以查看，其“下一张”仍按当前范围查找待复核回单。

刷新保留范围和正在编辑的表单。切换日期、选择全部日期或另开范围时，先检查是否有未保存修改；取消切换会保留原范围与表单。

“稍后”是本轮保存为稍后处理的回单数。“待处理”只计算当前范围内尚未处理且未留待稍后的回单。例如修改日期使某张回单不再符合原筛选，或其他窗口已完成该回单，刷新后不会再次从待处理数量扣减它。此统计随分页响应返回，不需要为计算进度加载所有结果页。“重新查看稍后处理项”会清除本轮跳过标记，并继续遵守当前范围。

## 快捷操作

| 操作 | 快捷方式 |
| --- | --- |
| 保存并稍后处理 | Ctrl／⌘ + S |
| 确认通过并继续 | Ctrl／⌘ + Enter；须满足日期、印章确认条件 |
| 定位日期／印章 | Alt + D／S |
| 放大／缩小图片 | +／−，或按住 Ctrl／⌘ 滚轮缩放 |
| 返回原页面 | Esc；未保存时仍提示确认 |
| 调整面板宽度 | 拖动中间分隔线；分隔线获得焦点后可按左右方向键，Home 恢复默认比例 |

定位与单键缩放在文字输入框中不触发，输入法组词期间也不触发快捷动作。
