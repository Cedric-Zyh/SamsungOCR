# 工作台与复核区改版

采用现有回单列表的浅蓝灰表头、淡米色待复核行、细边框、小尺寸描边按钮和状态标签。导入仍为弹窗；识别设置的模板内容、布局和配置逻辑保持不变。

## 工作台

- 默认进入工作台，按导入日期汇总后台队列和已有回单。
- 处理状态、日期核验、印章核验和整体核验分列展示。排队/识别中的重试不展示上一次的通过结论，识别失败不等于核验不通过。
- 支持全部、待复核、处理中、失败、不通过、通过筛选；优先排列待复核与失败项。
- 行内进入复核、重试或补传。返回工作台保留筛选与滚动位置。

## 复核工作区

- 当日复核与单张复核使用同一个整页工作区，移除原来的整页/弹窗双重实现；待复核队列可展开收起。
- 左侧图片支持整页、已保存的日期/印章原色区域图以及缩放。没有区域图时明确回退到整页，不生成或虚构定位。
- 右侧先展示疑点，日期与印章核验保持可见。印刷字段、签收填写、商品明细、识别依据、修改记录和样单标注按需展开。
- 保存期间锁定表单，防止重复提交；失败保留输入；离开或切换回单前保护未保存修改。
- 保存并稍后处理会在当前复核轮次中跳过该张，不循环返回；本轮结束后可以重新查看。稍后集合仅属于当前页面会话，不改变数据库里的待复核状态。
- 队列排除识别失败与正在重新识别的回单；它们通过工作台继续处理。
- 未开启商品识别与未检出商品区分显示。实收、拒收数量继续留空并标注待单证通提供。

## 日期确认与跨天重试显示修正（2026-09-10）

- “要求到货”只展示要求值，“签收日期识别”单独展示实际识别状态。列表列名也明确为签收日期、客户印章。
- 未识别日期时先询问是否为要求到货当天；选择“是，同一天”后采用要求日期，选择“不是，修改日期”才展开编辑器，并从要求到货日期开始。
- 展开编辑器的预填值不作为已确认日期保存；改为其他有效日期后才提交。缺少要求日期时提供手动填写入口，不生成今天或其他推断日期；修改要求日期会清除本轮原有日期选择。
- 工作台及按日复核队列使用 `include_queue=1` 补齐当天队列关联的结果。跨天重试保留原始导入日期，通过结果 ID 补齐数据；同名文件不互相替代，已删除回单不重新出现。其他日统计查询保持原有范围。
- 列表与详情共用识别状态展示规则：可靠匹配显示“匹配”；仅比对匹配、证据不可靠时显示“匹配待确认”，疑点说明相应原因。
- 本轮针对日期选择、跨天重试、同名文件、删除过滤、队列、人工复核保存与字段的 50 项回归通过；真实浏览器验证了预填值不保存、明确确认后日期及字段同步、连续复核以及桌面/390 像素布局。验证使用临时数据库。

## 回单记录表头实时筛选（2026-09-10）

- 移除表格上方的大块查询表单，将文件名、订单号、客户、签收日期、日期核验、印章核验、整体结论与复核状态筛选放入对应表头。文件名、订单号按前缀匹配，客户名称按包含匹配。
- 输入停顿 250 毫秒自动查询，日期与下拉选择立即查询；中文输入法组合期间不查询。仅更新表格内容，保留输入焦点；取消旧请求并拦截过期结果。
- 清空筛选保留导入日期和批次范围。快捷状态与表头整体结论同步；新筛选开始时清空原选择，避免对旧结果进行批量操作。
- 新增筛选参数同样用于 Excel 导出。未启用前缀模式的原有接口调用保持包含匹配。
- 32 项相关回归通过，覆盖前缀排除中间字符命中、内部订单字段、核验可靠性、列表与导出一致性。临时数据库浏览器验证了输入即查、组合筛选、重置、快捷状态、焦点、中文输入和过期响应；窄屏通过表格内部横向滚动查看各列。

- 后续简化：文件名与订单号合并为一个输入框，使用 `search_prefix` 同时匹配两者的开头，任意命中即可显示；列表与导出共用此条件。20 项数据库和接口回归通过，包含仅订单号命中、仅文件名命中及导出范围一致性。

## 工作空间整合与暂停入口（2026-09-10）

- 工作台、回单记录使用一致的标题、间距、细边框、浅蓝灰表头和待复核浅米色底。工作台保留紧凑统计条、优先待复核/失败的任务表，增加持久化全局暂停与继续，提示明确区分正在收尾与完全暂停。
- 记录表合并为八列（包含勾选）：文件名/订单号、客户、要求到货/签收、客户印章、核验结论、处理时间、操作。去除重复标题，导出与导入日期位于同一栏。文件名突出基础名称，文件夹相对路径在下一行展示并可悬停查看，后台识别信息留在详情。
- 文件名/订单号依旧单输入、150 毫秒前缀查询；客户包含查询。日期列的漏斗展开签收日期和日期核验两个条件，结论列展开核验结论和人工复核状态；弹层在滚动表格外定位，避免被裁切。活动条件标蓝，Escape/外部点击关闭；组合条件和导出沿用同一表单。
- 行内只保留复核/查看和更多菜单，更多提供重新识别、删除回单；桌面操作列取消遮挡式固定。桌面 1440 像素宽度可完整展示八列，小屏表格内部横向滚动。
- 复核区按约六成图片、四成表单布置。日期和印章采用可展开核验卡，可靠匹配默认收起，未识别、部分匹配、证据不足默认展开；点击问题提示可展开对应卡并定位证据。状态统一显示在卡片标题处，要求到货不再被签收识别状态混淆。
- 保留“是否要求到货当天”的确认流程、修改日期从要求日期起始、印章双路判定、九项输出字段和独立商品开关。识别设置和导入弹窗的功能保持原有方式。
- 隔离数据库浏览器验证前缀查询、日期与结论筛选、重置、更多菜单、核验卡展开、日期确认，以及桌面和 390 像素复核布局。暂停/继续测试不操作真实队列。

## 日期与印章确认简化（2026-09-10）

- 日期采用勾/叉图标确认是否为要求到货当天。勾选后收起询问，按要求日期信息行的相同样式显示签收日期；可点修改重新展开。选叉后日期编辑器从要求日期起始，改填实际日期后勾选收起。未确认的起始日期不作为实际日期保存。
- 客户印章同样使用勾/叉确认与签章要求是否一致。识别文字以信息行展示，可按需编辑；确认后显示匹配/不匹配，模板识别和文字 OCR 依据默认折叠。
- 印章的人工选择单独通过 `seal_confirmed_match` 保存，保存待复核也会保留明确的人工选择；没有人工确认的双路结果继续按原逻辑保留。修改印章内容或签章要求后需重新确认。保留原双路证据供审计，手工“不匹配”不能通过整体确认通过校验。
